# Spectral résumé fonts

Spectral by Production Type, distributed under the SIL Open Font License in `OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/spectral

The four WOFF2 files contain regular, bold, italic, and bold italic styles, subset to Latin and résumé punctuation (U+0020–00FF, U+2010–2027, U+25CF). They are bundled locally so the One-pager web view and PDF use the same fonts without network access.
